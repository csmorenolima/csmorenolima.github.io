Daily prayer delivery, fully automated.

Morning Prayer Bot is a lightweight iPadOS workflow that monitors a YouTube prayer feed, adds a motivational message, and shares the latest daily video with a WhatsApp group.

The problem

Daily sharing depended on someone remembering to do it.

Each morning, the latest prayer video had to be found and posted manually. The routine was easy to delay or miss.

The solution

Turn the morning routine into one scheduled action.

Apple Shortcuts checks the channel and shares the latest video with a motivational message at the chosen time.

Challenges and fixes

Making a small workflow dependable.

Reliability depended less on adding tools and more on controlling input, state and failure points.

Challenge

Feed data included more information than the workflow required.

Response

Extract only the title, link, publication date and thumbnail before continuing.

Challenge

Repeated scheduled runs could post the same video more than once.

Response

Compare each feed item against a locally stored reference to the previously delivered video.

Challenge

Apple Shortcuts required predictable data structures to avoid broken runs.

Response

Convert the RSS feed into JSON before parsing and accessing individual values.

Challenge

The project needed to stay lightweight and manageable without a server.

Response

Use existing services and local device automation rather than building custom infrastructure.

Challenge

The final WhatsApp action may pause while the host iPad is locked.

Response

Schedule delivery for a time when the iPad is available, or unlock the device to complete the foreground WhatsApp hand-off.

Future development

Focused improvements for the next version.

Further development would concentrate on message variety, observability and configuration rather than making the core workflow more complex.

  1. 01

    Rotating message library

    Fetch a different motivational message from a small remote library each morning so that repeated wording does not lose its impact over time.

  2. 02

    Error alerts

    Send a private notification when retrieval, parsing or delivery fails.

  3. 03

    Message Appearance

    Include the MPB character in each daily message to make it more recognisable and engaging.
